<h1 align="center">OpenBy</h1>

<p align="center">根据文件所在位置，自动选择合适的应用打开。</p>

<p align="center"><a href="README.md">English</a> · <strong>简体中文</strong></p>

---

OpenBy 是一款原生 macOS 文件打开方式管理工具，可以根据文件类型和所在文件夹，自动选择用于打开文件的应用。设置好规则后，在 Finder 中双击文件，就会交给你指定的应用。

例如，文献文件夹里的 PDF 论文可以用 PDF Expert 打开，其他文件夹里的 PDF 则用系统“预览”打开。

## 主要功能

- **按文件夹指定应用** — 为指定文件夹设置打开方式，也可将规则应用到子文件夹。
- **按文件类型设置默认应用** — 没有匹配的文件夹规则时，使用该文件类型的默认应用。
- **按优先级匹配** — 自由排列规则顺序，使用第一条匹配的规则。
- **常驻菜单栏** — 支持登录时启动，关闭设置窗口后仍可处理文件打开请求。
- **恢复原有打开方式** — 停用自动打开时，可恢复之前的应用关联。
- **配置保存在本机** — 无网络请求或遥测。
